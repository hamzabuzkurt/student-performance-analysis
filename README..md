# Student Performance Analysis

## Project Overview

This project focuses on analyzing student academic performance using Python.

The main objective is to explore the Mathematics dataset and understand how different factors are related to students' final grades.

## Objectives

- Explore student academic data.
- Analyze student performance.
- Compare academic performance by gender.
- Study the relationship between study time and final grades.
- Analyze past failures and absences.
- Explore parental education and student support.
- Understand correlations between numerical variables.
- Create meaningful data visualizations.

## Dataset

The project uses the Student Performance Mathematics dataset.

The dataset contains information about students, including:

- Gender
- Study time
- Past failures
- Absences
- Mother's education
- Father's education
- Family support
- School support
- Internet access
- Extracurricular activities
- Final grades

## Key Findings

The analysis found that previous academic grades have a strong positive relationship with final grades. Study time showed a weaker positive relationship.

Other factors, including past failures, absences, parental education and student support, were also explored.

## Conclusion

This project demonstrates how Python can be used to analyze educational data, identify patterns and create meaningful visualizations.

It also provided practical experience with important Data Science libraries and techniques.
